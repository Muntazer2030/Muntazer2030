## ⭐ Featured project: UPS Power Saver

**One-key power saving for Windows PCs on a UPS.** When the power cuts out, press a shortcut and the app limits your CPU
and GPU power so the UPS battery lasts longer. When the electricity is back, press it again and everything returns to normal.

<p align="center">
  <img alt="UPS Power Saver overlay" src="https://raw.githubusercontent.com/Muntazer2030/ups-power-saver/main/docs/overlay-advanced.png">
</p>

- ⌨️ Toggle with a global shortcut (rebindable), start with Windows, lives in the tray
- 📊 Live on-screen overlay: CPU/GPU watts, volts, temperature, clocks and FPS, with a *Simple* (total watts) or *Advanced* mode
- 🛠️ Adjustable CPU and GPU limits, overlay look and shortcuts
- 🔓 Free and open source (C#, single `.exe`)

👉 **[Get it on GitHub](https://github.com/Muntazer2030/ups-power-saver)**

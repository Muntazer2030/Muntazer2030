## ⭐ Featured projects

### 🔐 [Fingerprint Attendance System](https://github.com/Muntazer2030/fingerprint-attendance-system)
**ESP32-C3 · C · Ethernet + Wi-Fi · REST API · Flutter**

A complete product for a 10–50 person business: a wall-mounted fingerprint terminal and a Windows app that turns punches
into timesheets and payroll.

- Works offline: a 40,960-record flash log that survives power cuts, and a sync protocol that never loses or duplicates a punch
- Ethernet with automatic Wi-Fi fallback, and Telegram alerts sent by the terminal itself
- Admin app with fingerprint enrolment, shifts, overtime, payroll and Excel export, in Arabic and English
- 179 automated tests and a simulated terminal for testing without hardware

### 🧪 [Smart Logic Lab](https://github.com/Muntazer2030/smart_logic_gates_trainer_board)
**ESP32 · C · MQTT · BLE · Python · Flutter**

A networked lab for teaching digital electronics: an ESP32 board on every bench checks the circuit the student wired.

- ~17,000 lines of ESP-IDF firmware that tests circuits against truth tables, including clocked ones like flip-flops
- Zero-touch setup for a whole lab: BLE Wi-Fi provisioning, UDP server discovery, MQTT status, self-recovering boards
- Python server plus a [student app](https://github.com/Muntazer2030/smartLogic) and an [instructor app](https://github.com/Muntazer2030/logic_board_master) with live view of every bench

### ⚡ [UPS Power Saver](https://github.com/Muntazer2030/ups-power-saver)
**C# · Windows · hardware sensors**

One shortcut caps CPU and GPU power during a power cut to stretch UPS battery time, with a live overlay of watts,
voltages, temperatures, clocks and FPS.
